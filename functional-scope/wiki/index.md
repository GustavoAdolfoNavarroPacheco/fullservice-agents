# Índice de alcances funcionales

Catálogo de proyectos. Una línea por proyecto, actualizada en cada entrega. La versión vigente es la que enlaza esta tabla.

## Estados válidos
- `Borrador` — con pendientes BLOQUEANTES abiertos o sin pasar el control de calidad.
- `Apto para revisión final` — control de calidad completo; falta revisión técnica, comercial y jurídica.
- `Aprobado por cliente` — validado/firmado por el cliente.

> Nunca «listo para firma» con pendientes BLOQUEANTES.
