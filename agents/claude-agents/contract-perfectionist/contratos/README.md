# Contratos

Output final del agente: contratos listos para firma, uno por cliente.

- Un subfolder por cliente: `contratos/<cliente-slug>/`.
- Archivo final: `Contrato - <Cliente> - <YYYY-MM-DD>.docx`.
- No se mezcla información de un cliente en la carpeta de otro. Cada carpeta es independiente y confidencial.
- Cualquier borrador intermedio (`.md`) puede vivir en la misma carpeta del cliente, claramente marcado como borrador, hasta la entrega final.
